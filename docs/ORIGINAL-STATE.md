# Original-state and preservation record

## Recovered inventory

The recovered directory contained 11 files: 6 Python source files, 2 text notes, and 3 Python bytecode files. Specifically: `blockchain/block.py`, `blockchain/blockchain.py`, `blockchain/transaction.py`, `blockchain/wallet.py`, three `blockchain/__pycache__/*.pyc` files, `server/server.py`, `server/inf.txt`, `infs.txt`, and `notify.py`. There was no `.git` directory, README, dependency manifest, license, test suite, or other project documentation.

The source shows Python and Flask, with `flask_cors` used by the API and `requests` used by the notification script. No dependency versions were recorded. Source sizes ranged from 635 to 3,109 bytes; the complete inventory and byte sizes are retained in the local-only `.preservation/original-manifest.json`.

- `blockchain/__pycache__/*.pyc`: excluded as generated bytecode, not needed to understand the source, and potentially capable of retaining embedded values.
- `notify.py`: retained with only the hardcoded Telegram token and chat ID values replaced by `<REDACTED_HISTORICAL_SECRET>`.
- `server/server.py`: retained with only the hardcoded mining secret value replaced by `<REDACTED_HISTORICAL_SECRET>`.
- `.preservation/`: local untouched copy and manifest; Git-ignored and not part of the public edition.
- Added `.gitignore`, `README.md`, and the five historical documents in `docs/`.
